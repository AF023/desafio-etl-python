# 🚀 Projeto Pipeline ETL com Python

Repositório criado para praticar o fluxo de **ETL (Extract, Transform and Load)** utilizando a linguagem Python e manipulação de arquivos CSV.

## 🛠️ Tecnologias Utilizadas
- **Python**: Linguagem principal de programação.
- **Pandas**: Biblioteca para manipulação e tratamento de dados.

## 📋 Como o Projeto Funciona
1. **Extract (Extração):** Lê os dados brutos de um arquivo CSV contendo informações de clientes (`clientes.csv`).
2. **Transform (Transformação):** Aplica regras de negócio automatizadas gerando mensagens personalizadas para cada registro.
3. **Load (Carregamento):** Salva os dados transformados e enriquecidos em um novo arquivo de saída (`clientes_processados.csv`).

## ⚙️ Como Executar
1. Certifique-se de ter o Python e a biblioteca Pandas instalados (`pip install pandas`).
2. Execute o script principal:
   ```bash
   python main.py
